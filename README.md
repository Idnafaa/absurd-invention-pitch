One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: the Bedtime Bouncer, a lamp that dims a little more every time you whisper "just one more video", then escorts your phone to the charger like a tiny bouncer clearing the club at closing time.

## Run it

```sh
python3 main.py
```

The pitch is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
